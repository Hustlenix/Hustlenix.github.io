About the project

Small experiments, explained properly.

Hustlenix is an independent hobby project focused on creative software that works directly in the browser. The aim is simple: build things that are interesting to use, then document the ideas behind them clearly enough that another curious person can learn from the project instead of only seeing a finished demo.

Current flagship: Infinite Colour Craft

Infinite Colour Craft began with a question: what if a color picker became a discovery system? Instead of selecting any swatch instantly, players begin with a limited set of pigments and combine them to unlock more colors. The discovered colors can then be used in a full paint studio.

The project combines several browser technologies: a perceptual RYB-style color mixing engine, Canvas 2D painting tools, procedural Web Audio sounds, local browser storage, daily challenge logic, and a small convolutional neural network whose trained weights run locally to guess doodles.

Why the learning guides exist

A game about color is more useful when it also explains what the player is noticing. The learning section therefore covers practical color theory, additive versus subtractive mixing, deliberate mixing methods, and short digital-painting exercises. These are written specifically for this site rather than copied from other sources.

The guides distinguish simplified artist models from physical color science. For example, RYB is useful for painterly intuition but is not presented as a complete spectral model of real pigments.

Editorial approach

Articles on Hustlenix are written around techniques that can be demonstrated or tested. When a concept is simplified, the page says so. When a feature refers to the game, the description is based on the actual implementation in the public project repository.

The site does not publish scraped articles, automated news rewrites, or pages created only to target a keyword. New pages are added when they can provide a concrete explanation, exercise, or reference connected to the projects being built.

Open development

The source code for Hustlenix projects is published on GitHub. Bugs and technical questions can be reported through the project repositories, and the browser projects can be used without creating an account.
