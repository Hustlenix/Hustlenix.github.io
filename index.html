What makes the project different

It treats paint like paint, not light.

Computer screens normally combine red, green, and blue light. Physical paint behaves differently because pigments absorb light rather than emit it. Infinite Colour Craft uses a perceptual red-yellow-blue mixing model so familiar combinations behave more like the paint box people expect: yellow with blue trends toward green, and mixes are mapped back to recognizable named colors.

The point is not to replace professional color science. It is to make the difference between additive light mixing and subtractive pigment mixing visible and interactive.

Built in the browser

No install, no cloud AI required.

The app uses React, TypeScript, Canvas 2D, Web Audio, and an on-device neural network. Brush sounds are synthesized at runtime, drawings stay in the browser, and the doodle model performs inference locally.
