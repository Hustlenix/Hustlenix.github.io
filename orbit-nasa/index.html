DATA LINK CONFIGURATION

NASA API access

ORBIT can run with NASA's shared DEMO_KEY, or with your personal NASA Open APIs key for a larger request quota.

Security model: the key is stored only in this browser's localStorage and inserted directly into NASA requests. It is never committed into this GitHub Pages build. If a key has been exposed publicly, rotate it before using it.
