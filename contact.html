Contact

Feedback, corrections, and bug reports

The best place to contact Hustlenix about a project is GitHub, because a public issue can include screenshots, reproduction steps, and follow-up discussion without requiring a separate account system on this site.

Project bugs

Visit the Infinite Colour Craft repository and open an issue. Include the browser/device, what you were doing, what you expected to happen, and what happened instead. Screenshots are especially useful for canvas, color-mixing, or layout problems.

Article corrections

If a learning guide contains a technical mistake or an explanation that is unclear, use the Hustlenix.github.io repository to report the exact page and paragraph. Corrections are preferable to quietly leaving misleading information online.

General project feedback

You can also use the GitHub profile at github.com/Hustlenix to find the relevant repository. Please do not include passwords, API keys, private account information, or other sensitive data in public issues.

Security: never post secrets or access tokens in a public GitHub issue. Revoke any credential immediately if it has been exposed.
